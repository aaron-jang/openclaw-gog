Privacy Policy

Last updated: 2026-11-12

OpenClaw gog is a private tool used only by its owner to access the owner's own Google account.

Data accessed

With the owner's consent, the tool accesses Google user data through the Google APIs for the scopes the owner approves, such as Gmail, Calendar, Drive, Sheets, Docs, Contacts, Tasks, Analytics and YouTube.

How data is used

Data is used only to perform tasks the owner requests from their personal assistant, such as reading mail, managing calendar events and producing reports for the owner.

Storage and sharing

OAuth tokens are stored encrypted on the owner's own server. Google user data is not sold, not shared with third parties, and not used for advertising. Parts of a request may be processed by the AI model provider the owner has chosen, only to carry out that request.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be raised through the project's GitHub issues.
